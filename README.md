# 🎮 Premium Sudoku Game

A modern, responsive Sudoku game built using **HTML, CSS, and JavaScript**. Enjoy a premium gaming experience with beautiful UI effects, multiple difficulty levels, smart hints, notes mode, and interactive gameplay.

## 🌐 Live Demo

🚀 **[Play Premium Sudoku](https://sehgal1001.github.io/premium-sudoku-game/)**

## ✨ Features

- 🎯 Four Difficulty Levels – Easy, Medium, Hard, and Expert
- 🧩 Random Sudoku Puzzle Generation
- ⏱️ Live Game Timer
- ❌ Mistake Counter
- ✏️ Notes / Pencil Mark Mode
- 💡 Smart Hint System
- ↩️ Undo Previous Move
- 🧹 Erase Functionality
- 📊 Live Game Progress Tracking
- 🌙 Dark and Light Mode
- 🏆 Best Time Tracking
- 🎮 Games Won Statistics
- ⌨️ Keyboard Shortcuts

## 🎮 How to Play

1. Select your preferred difficulty level.
2. Click on an empty cell in the Sudoku grid.
3. Enter a number between 1 and 9.
4. Complete every row, column, and 3×3 box without repeating numbers.
5. Use Notes mode to track possible numbers.
6. Use the Hint button if you need help.
7. Complete the puzzle and beat your best time!

## ⌨️ Keyboard Shortcuts

| Key | Action |
|---|---|
| 1–9 | Enter a number |
| Arrow Keys | Move between cells |
| N | Toggle Notes Mode |
| U | Undo |
| Backspace / Delete | Erase |

## 🚀 Installation & Setup

Clone this repository:

```bash
git clone https://github.com/Sehgal1001/premium-sudoku-game.git
```

Navigate to the project directory:

```bash
cd premium-sudoku-game
```

Open `index.html` in your browser or use the Live Server extension in VS Code.
